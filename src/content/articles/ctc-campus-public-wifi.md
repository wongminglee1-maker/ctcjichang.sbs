在高校宿舍、图书馆、机场候机厅或星巴克等公共场所使用 CTC 金龙鱼（又称金龙鱼机场）时，许多用户会遇到一种典型现象：连上公共 Wi-Fi 后，状态栏显示已分配网络，但打开代理客户端测试节点全部显示超时（Timeout）；或者浏览器不断弹出证书警告，甚至无法加载任何网页。

这种现象的核心症结，往往在于用户没有厘清受限网络环境下 **代理模式和直连模式区别**，以及公共网络部署的**Web 强制认证门户（Captive Portal）、内网 DNS 重定向及特定端口防火墙策略**。本文将指导大家如何在受管理网络环境中进行合规排查，快速恢复正常的网络连接。

---

## 校园网/公共 Wi-Fi 与家庭宽带的本质差异

家庭 Wi-Fi 接入后设备可直接向互联网发起任意协议的通信，而校园网与公共商用网络属于典型的“强管控受限局域网”：

```
[设备接入公共 Wi-Fi]
          │
          ▼
[未登录认证阶段 (未授权状态)]
  ├─ 阻断所有外部 TCP / UDP 流量 (包括 Shadowsocks / 代理握手)
  └─ 强制将所有 HTTP 请求重定向至认证页面 (Web Portal 登录)
          │ (通过学号/手机短信认证)
          ▼
[已授权阶段 (受限互联网访问)]
  ├─ 开放常规 Web 流量 (HTTP 80 / HTTPS 443)
  ├─ 强制由内网 DNS 解析外部域名 (可能引发 DNS 污染)
  └─ 严格审计并阻断高风险非常规端口及未经备案的 UDP 流量
```

| 对比维度 | 家庭独立宽带 | 校园网 / 公共 Wi-Fi |
| :--- | :--- | :--- |
| **接入授权** | 物理 Wi-Fi 密码直连，无需二次网页认证 | 必须通过 Web 登录页输入学号或手机短信验证码 |
| **端口开放策略** | 绝大多数出站端口（Port）默认全开放 | 通常仅开放 80、443 等常用端口，非标高位端口被直接 DROP |
| **DNS 服务** | 可自由自定义路由器及本机 DNS | 内网强制劫持 53 端口，阻止未加密的第三方 DNS 请求 |
| **并发与会话控制** | 依据设备自身负载，无强制掉线机制 | 通常限制单账号登录设备数，设有 2–8 小时超时下线机制 |

## 核心排查实操：解决认证死锁与连接故障

### 第一步：打破“先开代理导致认证页打不开”的死锁循环
这是导致校园网节点连接失败最常见的原因：用户在进入校园网前就开启了代理软件，当设备连接到校园 Wi-Fi 后，网关尝试将浏览器重定向到内网认证 IP（如 `10.254.1.1` 或 `172.16.0.1`）。然而，由于代理客户端接管了浏览器流量，代理软件尝试将内网重定向包发送到境外的 CTC 节点，最终形成死锁循环。

**正确做法**：
1. **立即彻底关闭客户端**：在电脑或手机上退出代理软件，关闭系统代理开关。
2. **强制呼出认证门户**：打开浏览器无痕模式，在地址栏输入一个不带 HTTPS 的纯 HTTP 地址（如 `http://neverssl.com` 或 `http://1.1.1.1`）。
3. **完成登录并验证直连**：输入账号密码或短信验证码完成认证，在直连状态下随意刷新一个国内网站，确认物理网络已获得完整的互联网访问权限。
4. **重新开启客户端连接**：此时再启动 CTC 客户端，节点即可正常与外网中转服务器完成握手。

### 第二步：规避内网 DNS 劫持与配置加密 DOH
公共 Wi-Fi 的内网 DNS 往往会对特定服务域名进行污染，甚至直接返回局域网网关地址，导致 CTC 客户端无法解析到真实的专线入口 IP。

**解决方法**：在客户端中配置加密 DNS（DNS over HTTPS，即 DOH），绕过局域网 53 端口的明文劫持：
- 推荐使用腾讯公共 DOH：`https://doh.pub/dns-query` 或阿里 DOH：`https://dns.alidns.com/dns-query`。
- 在客户端配置文件中，将内网不加密 DNS 剔除，确保所有解析请求均通过 443 加密通道直达权威公共解析服务器。

### 第三步：针对端口受限环境的对照测试
部分严格的校园实验室网络或企业访客 Wi-Fi 会部署深度包检测（DPI），直接拦截所有 Shadowsocks-2022 流量。
- **快速对照判断**：打开手机蜂窝移动热点，将电脑连接到手机 5G/4G 网络。
- 如果在手机热点下 CTC 专线秒连且延迟极低，但一切换到校园网就全量超时，即可 100% 确认是校园网防火墙策略对端口或协议进行了过滤限制，而非您的软件配置或节点损坏。

## 合规使用倡议与安全提示

在享受网络互联便利的同时，请务必遵守所在高校或公共场所的网络安全管理制度：
1. **不得利用校园网络从事违规操作**，遵循学术与学习用途原则。
2. **在公共无密码 Wi-Fi 中保持警惕**：未加密的公共 Wi-Fi 存在中间人监听风险，切勿在未开启端到端加密的环境下传输敏感个人信息。
3. **保护个人账户凭据**：在公共电脑上使用时，切勿保存私有订阅链接。如需了解完整的网络自检报告生成方法，请使用本站 [网络连接交互自检中心](/diagnostics/)，或参阅 [CTC 故障沟通与工单模板](/guides/ctc-support-report/)。
